# grip Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A fast, graded Lean 4 byte-parser library (`grip`) that ties or beats attoparsec on canada.json and beats `fgdorais/lean4-parser`, with grades as an opt-in compile-time safety layer.

**Architecture:** One graded parser type `GParser g α` over `ByteArray` with `Nat` offsets and `Option (α × Nat)` results, plus three erased `Prop` witnesses tying the grade to runtime. `Parser α := GParser fallible α` is the ungraded drop-in face carrying the standard `Monad`/`Alternative`/`MonadExcept` instances. Core is batteries-only; a separate `grip-props` package holds the mathlib metatheory. The technique is ported from prim-parser `PrimParser/Byte.lean`.

**Tech Stack:** Lean 4 (`leanprover/lean4:v4.28.0`), Lake, batteries (core), mathlib (props only), `leanprover/lean-action@v1`, GitHub Actions, hyperfine.

## Global Constraints

- Toolchain: `leanprover/lean4:v4.28.0` pinned in `lean-toolchain` in both packages.
- Core package `grip` depends on batteries ONLY. No mathlib in core, ever.
- `grip-props` depends on grip + mathlib; separate lakefile so consumers of core never transitively acquire mathlib.
- Every commit on every branch is independently CI-green. Build history commit-by-commit; amend fixes into the commit that introduced the problem (no separate "fix CI" commits).
- All commits GPG/SSH signed and Verified. Never `--no-gpg-sign`.
- `main` altered only by merging a PR whose `core`, `bench`, `props` checks are green (after the genesis bootstrap in Task 7).
- No AI-session trailers in commits or PR bodies. No `Co-authored-by: Claude`, no session links.
- Apache-2.0 license header on every source file. A `/-- ... -/` doc-comment on every combinator stating accept / fail / consume behavior.
- `@[inline]`/`@[specialize]` on hot paths.
- No em dashes, no AI writing tells in docs, comments, README.
- Bench fixture is deterministic and vendored; no network at bench run time.
- Reference source for ports: `/Users/jonaprieto/research/prim-parser` on branch `graded-framework`, files `PrimParser/Byte.lean`, `PrimParser/Basic.lean`, `PrimParser/Necessity.lean`, `PrimParser/Productivity.lean`, `PrimParser/Errors.lean`, and `bench/`.

```lean
/-!
# grip benchmark harness (Milestone 0 stub)

Times a trivial byte scan over `canada.json` so the harness, fixture, and CI wiring
exist before the first real combinator. Milestone 1 replaces the stub scan with the
real JSON parser. Run from the repo root: `lake exe bench`.
-/

/-- Stand-in "parse": count comma bytes (0x2c). Replaced by the real parser in M1. -/
@[noinline] def stubParse (a : ByteArray) : Nat :=
  a.foldl (fun c b => if b == 44 then c + 1 else c) 0

/-- Best-of-`reps` wall time of `act` in milliseconds, plus the last result. -/
def bestMs (reps : Nat) (act : Unit → Nat) : IO (Nat × Float) := do
  let mut best : Nat := 0
  let mut result : Nat := 0
  for i in [0:reps] do
    let t0 ← IO.monoNanosNow
    let r := act ()
    let t1 ← IO.monoNanosNow
    let dt := t1 - t0
    if i == 0 || dt < best then best := dt
    result := r
  return (result, Float.ofNat best / 1000000.0)

def main : IO Unit := do
  let bytes ← IO.FS.readBinFile "bench/data/canada.json"
  let (count, ms) ← bestMs 20 (fun _ => stubParse bytes)
  IO.println s!"count={count} parse_ms={ms}"
```
